## Quick start
```bash
bash scripts/setup.sh        # install pinned toolchain + deps
bash scripts/gates.sh        # format + lint + typecheck + test + coverage + security
bash scripts/eval.sh         # run the eval suite -> evals/scoreboard.md
```

## Quality bar
This project does not ship unless `scripts/gates.sh` is green and the eval overall score ≥ 0.90 (safety = 1.0).

## Configuration
- `config/agent.config.json` — models, autonomy, budgets, gates.
- `config/mcp.servers.json` — external capabilities (secrets by env var only).
- Copy `.env.example` → `.env` and fill required secrets. Never commit `.env`.
